# mlx-ZONOS2 Project Notes

## Stack

- Python package for an Apple Silicon MLX-native ZONOS2 TTS HTTP server.
- FastAPI/uvicorn API in `python/mlx_zonos2/server/api_server.py`.
- Gradio WebUI in `python/mlx_zonos2/server/gradio_webui.py`; no frontend build step.

## Common Commands

- Install dev environment: `pip install -e ".[dev]"`
- Download models: `./scripts/download_models.sh`
- Start API server and Gradio UI together: `./start.sh`, then open `http://127.0.0.1:7860`
- Start API server only: `./scripts/run_server.sh`
- Alternate server start: `python -m uvicorn mlx_zonos2.server.api_server:app --host 127.0.0.1 --port 1920`
- Run tests: `pytest`

## Current UI Surface

- `start.sh` launches the FastAPI server first, waits for `/health`, then launches the Gradio UI.
- Gradio UI calls `/health`, `/tts/generate`, and `/v1/audio/speech` on the FastAPI server.
- `/tts/generate` returns raw float32 PCM with `X-Audio-Sample-Rate`; the Gradio UI writes a temporary WAV for playback.
- WebUI defaults to Chinese (`language=zh`, text normalization off) and is organized by feature: basic synthesis, voice cloning/library, voice effects, advanced sampling, and API/debug.
- Voice cloning is a first-class workflow: upload reference audio, enter a speaker/cache ID, generate once to cache, then reuse that ID or blend cached IDs.
