# mlx-ZONOS2 Memory

- Main WebUI is Gradio: `python/mlx_zonos2/server/gradio_webui.py`, launched together with the API via `./start.sh`.
- Gradio UI calls the existing FastAPI API server and converts returned PCM to temporary WAV files for playback.
- WebUI defaults to Chinese and exposes voice cloning as a main workflow, not an advanced parameter tab.
